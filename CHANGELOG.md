# Changelog

## v0.1 — Initial public release

**My first project**, built through **Vibe Coding with AI assistance** and published as Z Hotspot by @zalem.j ([zalemjb](https://github.com/zalemjb)).

- Native Python/GTK desktop application for Linux.
- Compact dashboard and a full view with Overview, Connected devices, Share files, and Network settings.
- Hotspot start/stop, live signal and traffic measurements, device details, disconnect, and persistent MAC blocking.
- Wi-Fi join QR, password generator, source selection, hidden SSID, and client isolation settings.
- Local browser file downloads and optional uploads, transfer QR, and recent transfer activity.
- Background mode with a system tray menu.
- Debian package, portable source archive, English and Arabic documentation, and third-party license notices.
- User-local source installer for application menu integration across Linux distributions with the required dependencies.
- Z Hotspot logo, banner, and full/compact interface screenshots.

The package version is `0.1.0`; the public release tag and displayed version are `v0.1`.

### Verification scope

The project targets Linux desktops with its system dependencies available. See [TESTING.md](TESTING.md) for the actual hardware and automated-test environments. File-transfer tests use local HTTP connections and simulated browser profiles; physical iPhone and Samsung transfers are not claimed.
